## 二、Python 端逻辑错误

### Critical

| # | 文件 | 行号 | 问题 | 说明 |
|---|---|---|---|---|
| 1 | server.py | 2749 | **分页计算与前端不匹配** | 前端传 `offset=page*20`（page从0开始），后端用 `page` 参数（从1开始）。前端的 `page=0` → 后端 `offset=0` OK；前端 `page=1` → 后端 `page=1, offset=0` 实际返回第一页数据（本应是第二页）。每页都偏移一页，最后一页会空的。 |
| 2 | server.py | 1434 | **SQL UPDATE 在只读查询中** | search_memory 函数在 `db_conn()` 上下文中执行 UPDATE recall_count 写入操作，contextmanager 在 yield 前已 auto-commit，但 search 操作在每个 row 上做 UPDATE，这在并发场景下可能死锁或超时。 |
| 3 | server.py | 2167-2169 | **sync_heartbeat tool 参数校验可能失败** | handler 里传 `tool=arguments.get("tool", "unknown")`，但 `SyncHeartbeatRequest.tool` 的 pattern 是 `^(hermes\|claude\|workbuddy\|system)$`，`"unknown"` 不在枚举中，会触发 Pydantic 验证错误。 |

### Major

## 六、数据库 Schema 设计缺陷

### Major

| # | 表 | 问题 | 说明 |
|---|---|---|---|
| 25 | `session_memories` | **缺少 ON DELETE CASCADE** | `session_memories.memory_id` 的外键定义缺少 `ON DELETE CASCADE`（line 143-144），所以在 delete_memory (line 1618) 需要手动 DELETE。但 memory_relations 和 memory_versions 有 CASCADE。前后不一致。 |
| 26 | `change_log` | **缺少 ON DELETE CASCADE** | 同上，`change_log` 也没有 CASCADE（line 147-153），需要手动删除。 |
| 27 | `categories` | **`parent_id` 递归引用可能产生循环** | 外键 `parent_id REFERENCES categories(id)` 没有约束防止循环引用。可能产生 A→B→C→A 的循环。 |
| 28 | `memories` | **无 `UNIQUE(content, source)` 约束** | 虽然通过 checksum+simhash 做逻辑去重，但数据库层没有唯一约束。并发场景下可能写入重复。 |

| # | 表 | 问题 | 说明 |
|---|---|---|---|
| 29 | `memories` | **`created_at`/`updated_at` 无 DEFAULT 约束** | 代码中手动填充时间，但 schema 定义没有 DEFAULT。 |
| 30 | `memories` | **`embedding` 列使用 BLOB 但未使用** | `row_to_dict()` (line 493) 显式 `d.pop("embedding", None)`，说明该字段在应用层已废弃但 schema 仍保留。 |

## 八、最关键修复优先级

1. **🔴 前端 `dashboard_memories` → 后端字段名 `items` vs `memories`** → 列表永远为空
2. **🔴 前端 `dashboard_memory_detail` → 嵌套 `memory` 对象未解包** → 详情面板全空白
3. **🔴 前端 `timeline.days.map()` → 数字不能 `.map()`** → 图表页 JS 崩溃
4. **🔴 前端 `health.sync` vs `health.sync_status`** → 同步状态永远不显示
5. **🔴 分页参数 `offset` vs `page` 不对称** → 数据错位一页
6. **🔴 `m.version` 字段缺失** → 列表显示 "vundefined"
7. **🟠 XSS: 版本历史 `change_reason` 未转义** → 可能执行恶意脚本
